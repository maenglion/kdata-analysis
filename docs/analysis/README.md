# K-DATA 사건 분석 기록

이 디렉터리는 새 회신·증거가 들어왔을 때 기존 판정에 미치는 영향을 공개 가능한 범위에서 기록한다.

## 기록 원칙

- 기관 원문, 사용자 주장, 파생 분석을 서로 다른 증거층으로 구분한다.
- 기관이 어떤 사실을 공식 회신했다는 사실과 그 회신 내용이 객관적으로 참이라는 판단을 구분한다.
- 원본 사건자료, 연락처, 이메일 주소, 주소, 인증정보와 로컬 절대경로는 저장하지 않는다.
- 현재 판정은 소스코드에서 바로 고치지 않고, 향후 루브릭 기반 evaluation run으로 이관할 입력으로 기록한다.
- 새 자료가 기존 판정을 바꾸더라도 이전 판정을 삭제하지 않는다.
