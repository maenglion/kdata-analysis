# K-DATA 의사결정 기록

이 디렉터리는 K-DATA Evidence Ledger의 중요한 설계·운영 결정을 공개 가능한 범위에서 기록한다.

## 기록 원칙

- 결정의 배경, 채택 내용, 근거, 영향, 보류사항을 함께 기록한다.
- 이후 결정이 바뀌어도 기존 문서를 삭제하거나 소급 수정하지 않고 새 기록에서 대체 관계를 밝힌다.
- 원본 사건자료, 개인정보, 인증정보, 로컬 절대경로는 기록하지 않는다.
- 코드와 DB의 실제 동작이 회의록과 다르면 코드·마이그레이션을 우선 검증하고 불일치를 새 이슈로 남긴다.
- 방법론 변경은 기존 버전을 수정하지 않고 새 `methodology_version`으로 추가한다.
